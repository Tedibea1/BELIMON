BELLYMON — 96 sprites découpés à partir de 16 planches originales
==============================================================

Personnages (ordre des planches, de gauche à droite puis de haut en bas) :
Vampire, Spectre, Némésis, Maudite, Envoûteuse, Exorciste.

Morphologies : commun/E ; musclee/D,C,B,A,S ; obese/D,C,B,A,S ; chetive/D,C,B,A,S.
Chaque fichier PNG mesure 512 x 512 pixels, découpe 1:1 sans redimensionnement ni retouche.
Les cadres originaux sont conservés. Les découpes E sont identiques à l'échantillon validé.

INTÉGRATION : ces sprites sont placés dans assets/characters/ de BELLYMON V13.
Ils ne sont PAS encore reliés à une classe jouable ni à la capture : il faudra
implémenter les six nouvelles héroïnes dans le code lors d'une étape distincte.
Les mécaniques et les sauvegardes de V13 ne sont pas modifiées.
