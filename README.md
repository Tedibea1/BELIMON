# BELIMON 🎮

**BELIMON** est le nouveau nom officiel du jeu auparavant appelé **BELLYMON**.

RPG fantasy jouable dans un navigateur : collection de waifus, exploration d'une tour, combats, nourrissage, transformations et progression des héroïnes.

**Version actuelle : V16.2.**

**Raccourcis de la tour :** le retour au record coûte désormais un nombre de steaks égal à l’étage ciblé (étage 100 = 100 steaks). Le retour cinq étages avant le record coûte la moitié du numéro de cet étage, avec arrondi au pair (record 100 → étage 95 pour 48 steaks). Ces raccourcis restent réservés aux étages déjà atteints ; les sauvegardes existantes sont conservées.

## Compatibilité

Le changement est **uniquement un renommage de l'identité affichée** :

- Les sauvegardes locales et leurs clés internes sont conservées.
- L'import des anciennes sauvegardes et archives est maintenu.
- Les nouveaux fichiers exportés sont nommés BELIMON, mais leurs formats de données restent compatibles.
- Les identifiants internes des modules JavaScript, les chemins de fichiers et les préférences audio ne changent pas.
- Les mécaniques de jeu, les illustrations, les sons et les transitions musicales ne sont pas modifiés.

Les fichiers README historiques, rapports et notes des versions antérieures conservent parfois le nom BELLYMON, conformément à l'historique du projet.
